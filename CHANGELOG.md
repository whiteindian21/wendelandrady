[1.0.0] - 2026-XX-XX
Added
Initial commercial release.
Next.js 15 App Router + React 19 foundation.
Supabase authentication (Email/Password, Google, GitHub) with SSR sessions.
Multi-tenant Organizations with secure context switching.
Role-Based Access Control (Owner, Admin, Member).
Secure invitation system with hashed tokens.
Stripe Billing integration (Monthly/Yearly, Checkout, Customer Portal).
API Key management with SHA-256 hashing.
Usage tracking and server-side plan limit enforcement.
Append-only Audit Logs.
In-app Notifications system.
Organization-scoped and global Feature Flags.
Projects CRUD example.
Strict Row Level Security (RLS) on every database table.
Comprehensive documentation and setup guides.
